## Problem

The "Ver histórico" button in the CRM correctly opens a modal, but the modal displays an error: "Não foi possível carregar o histórico de acessos." This indicates a failure in the `getVisitorHistory` server function or its integration with the frontend.

## Proposed Changes

### 1. Server-side Fix (`src/lib/crm.functions.ts`)

- **Robust Error Handling**: Wrap the main logic in a try-catch block. Log detailed error information (Supabase error codes, messages, stack traces) on the server.
- **Strict Authorization**:
  - Retrieve real session from context.
  - Resolve user role (ADM, Matriz, Filial).
  - Enforce data isolation:
    - ADM sees everything.
    - Matriz sees their HQ and branches.
    - Filial sees only their specific branch connections.
  - Return 403 (Forbidden) if the visitor does not belong to the authorized scope.
- **Connection Query Audit**:
  - Verify existence of columns: `company_id`, `branch_id`, `event_id`, `campaign_id`, `device_type`, `created_at`.
  - Ensure `campaign:campaigns(name)` relationship is correct.
- **Unit Resolution**:
  - Resolve unit names (Matriz, Filial, Evento) in batch to avoid N+1 queries.
  - Handle cases where IDs might be missing gracefully (fallback to "Unidade não identificada").
- **Pagination**: Implement limit/offset based pagination with a standard page size of 20.

### 2. Frontend Fix (`src/components/app/crm/VisitorHistoryModal.tsx`)

- **Correct Parameter Mapping**: Ensure `getVisitorHistory` is called with exactly `{ visitorId, page }`.
- **State Management**:
  - Replace infinite scroll logic with a "Carregar mais" button as requested.
  - Track `isFetchingNextPage` to disable the button during loads.
  - Preserve order and prevent duplicate entries.
- **Error States**:
  - Keep the modal open on error.
  - Provide a "Tentar novamente" button that triggers a re-fetch.
  - Show "Nenhum acesso encontrado" only when the list is truly empty (not on error).

### 3. Integration Fix (`src/routes/_authenticated/visitantes.tsx`)

- Verify that `setSelectedVisitorId` passes a valid `visitor_id` string.
- Ensure the modal is only mounted/triggered when a valid ID is present.
