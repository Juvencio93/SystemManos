# Plan: Fix Technical Terms in Operational Manager AI Analysis

Remove technical internal field names (like `connectionsPrev7d`, `companyId`, etc.) from the AI-generated text in the Operational Manager summary and replace them with natural language.

## User Review Required

> [!IMPORTANT]
> This change modifies the prompt sent to the AI to explicitly forbid the use of technical terms in its output. While the AI is instructed to use natural language, its creative output is non-deterministic; however, the new constraints are designed to be strict enough to prevent these terms from appearing.

## Proposed Changes

### AI Logic & Prompts

#### `src/lib/ai.server.ts`

- Update the `systemPrompt` for `generateGlobalOperationalSummary` to:
  - Explicitly forbid using technical keys (e.g., `connectionsPrev7d`, `companyId`, `lastConnectionAt`) in any text fields (`diagnosis`, `recommendation`, `prioridades`, `destaques`).
  - Instruct the AI to use "período anterior" or "sete dias anteriores" instead.
  - Add specific examples of natural language responses for units with short history (e.g., "1 dia de acompanhamento").
  - Reinforce that it should describe the fact (e.g., "registrou 0 conexões") instead of naming the variable.

#### `src/lib/operational.utils.server.ts`

- Review the fallback logic in `processUnit` and `buildInitialOperationalSummary` to ensure no technical terms are hardcoded in the deterministic strings.
- Update `processUnit` reasons to use the requested phrasing for new operations (e.g., "possui apenas X dias de acompanhamento").

## Technical Details

- No changes to data structures or database schemas.
- No changes to the frontend components (`gerente-operacional.tsx`, `OperationalUnitCard.tsx`).
- Validation will involve generating a new analysis and checking the output strings for forbidden patterns using `rg`.

## Validation Plan

1. **AI Output Audit**: Run a manual refresh of the Operational Manager and inspect the summary for any occurrence of the forbidden strings.
2. **Deterministic Fallback Check**: Verify that if the AI fails, the fallback strings generated by `operational.utils.server.ts` are also clean of technical terms.
3. **Automated Checks**:
   - `tsgo` to ensure types are intact.
   - `bun run build` to ensure no regressions.
